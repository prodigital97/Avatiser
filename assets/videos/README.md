# Portfolio video assets

Drop production clips here and the site picks them up automatically:

- `clip1.mp4 … clip8.mp4` — showcase strip cards (clip7 also plays as the hero background)
- `poster1.jpg … poster8.jpg` — poster frames shown while a clip loads

Keep clips short (5–15s), muted-friendly, and compressed (H.264, ≤ 3–4 MB each
is a good target). 9:16 for portrait cards; 16:9 for cards 02, 05 and 08.

Missing files are fine — cards fall back to styled placeholders.
