# Casting headshots: generate first, approve, then attach to every shot

Words alone drift: the generator will cast from its own defaults (in testing it kept
rendering the Chennai model as African). So lock each face once, the way
`studio/prompts/realism-core.md` §5 asks. Generate 4 of each, pick one, save it here as
`darjeeling.jpg` / `chennai.jpg`, and attach both photos (with the SKU photos) to every
campaign prompt. In Soul 2.0, store each pick as an identity and pass it on every shot.
